# taste-skill (design-taste-frontend)

Vendored from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT licensed),
the `taste-skill` folder only (install name `design-taste-frontend`) — the project's default,
actively-maintained skill.

Anti-slop frontend design guidance for landing pages, portfolios, and redesigns: reads the
brief, infers the right design direction, sets three "dials" (DESIGN_VARIANCE, MOTION_INTENSITY,
VISUAL_DENSITY), and steers the agent away from generic AI-generated UI defaults (purple
gradients, centered hero clichés, Inter everywhere, beige/brass "premium" palettes, etc.)
toward concrete, opinionated design systems and layout rules.

No external services or scripts are required — it's pure guidance for the coding agent,
picked up automatically by Claude Code from `SKILL.md`.

See `SKILL.md` for the full ruleset. Upstream repo: https://github.com/Leonxlnx/taste-skill
(see its README for the other skill variants in that project — brutalist, minimalist, soft,
redesign, image-to-code, etc. — not vendored here).
